Installs a selection of Odoo Community and OCA modules for a public demo
instance, so that people can try Odoo Community with the OCA modules that
cover what is otherwise only in Odoo Enterprise: accounting reports, bank
reconciliation, assets, follow-ups, documents, knowledge, sign,
spreadsheet, helpdesk, contracts and a timeline view.

The list is kept short on purpose. Modules were chosen if they are useful
in a first demo, maintained, and reasonably translated.

The module has no code or data of its own. Demo data comes from the
installed modules.
